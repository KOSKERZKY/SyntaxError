# Tipos de datos.
# Los tipos de datos en Python incluyen:
- Numéricos (int, float, complex)
- Secuencias (str, list, tuple), mapas (dict), conjuntos (set, frozenset)
- Tipo booleano (bool).
Cada tipo se utiliza para almacenar y manipular diferentes clases de información, definiendo los valores que una variable puede contener y las operaciones que se pueden realizar con ellos. 

### Tipos de Datos Numéricos
- int (Enteros): Representan números enteros sin parte decimal, como 5 o -10. 
- float (Flotantes): Representan números con parte decimal, como 3.14 o 2.0. 
- complex (Complejos): Representan números complejos con parte real e imaginaria, como 1+2j. 

### Tipos de Datos de Secuencia

- str (Cadena de texto): Son secuencias de caracteres (texto) que pueden contener letras, números y símbolos. 
- list (Lista): Colecciones ordenadas y mutables (modificables) de elementos que pueden ser de diferentes tipos. 
- tuple (Tupla): Colecciones ordenadas y inmutables (no modificables) de elementos. 

### Otros Tipos de Datos Importantes

- bool (Booleano): Representa valores de verdad: True (verdadero) o False (falso). 
- dict (Diccionario): Colecciones de pares clave-valor, donde cada clave es única. 
- set (Conjunto): Colecciones no ordenadas y sin duplicados de elementos.
