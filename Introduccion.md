# Que es Python?
Python **es un lenguaje de programacion** implementado en 1989 y oficialmente lanzdo el 2 de Febrero.  
Este lenguaje se **destaca** por lo **flexibilidad** al momento de hacer scripts ya que puedes programar para las mayoria de tus necesidades y lo **versatil** que es a la hora de programar ya que es facil de entender y facil de leer.  
Programar con este lenguaje por mas que parezca el ideal tiene sus desventajas que son:
- Consumo de recursos:  
Python puede consumir bastante memoria y energía, lo que limita su uso en el desarrollo móvil, donde la eficiencia de recursos es crucial.  
- Desarrollo móvil:  
La naturaleza del lenguaje no lo hace ideal para aplicaciones móviles, lo que restringe su popularidad en este campo.  
- Problemas en la comunidad de librerías:  
Si bien la gran comunidad de Python es una fortaleza, también puede llevar a tener módulos duplicados o a que algunas bibliotecas no estén maduras o se abandonen, lo que dificulta encontrar la solución más adecuada. 
- Dificultad con errores en tiempo de compilación:  
Al ser un lenguaje de tipado dinámico, los errores relacionados con los tipos de datos no se detectan hasta el tiempo de ejecución, lo que puede hacer la depuración más compleja. 

## Cuándo Python no es la mejor opción
- Aplicaciones de alto rendimiento:  
En proyectos que exigen velocidad máxima, como ciertos sistemas operativos o software de bajo nivel, lenguajes compilados como C++ suelen ser superiores. 
- Desarrollo móvil nativo:  
Para la creación de aplicaciones móviles que requieren máxima eficiencia y acceso a hardware de bajo nivel, otros lenguajes son más adecuados. 
- Sistemas críticos de producción:  
En servicios donde la estabilidad y la predictibilidad son fundamentales, las características de tipado dinámico de Python pueden ser una desventaja, según algunos profesionales.
